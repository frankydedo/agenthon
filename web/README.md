# Interfaccia web

React 19 + TypeScript + Vite + Tailwind v4. Documentazione completa: [../docs/frontend.md](../docs/frontend.md).

```bash
npm install
npm run dev        # http://localhost:5173 (serve il backend: uvicorn api.main:app --port 8000)
npx tsc -b         # controllo dei tipi
npm run build      # build in dist/
```
